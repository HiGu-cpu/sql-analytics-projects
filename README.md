# SQL Analytics Projects

This repository includes SQL projects focused on marketing analytics, revenue analysis, advertising performance, KPI calculations, and reporting-ready datasets.

## Tools Used

- SQL
- PostgreSQL
- DBeaver
- Facebook Ads Dataset
- Google Ads Dataset

## Projects

### 1. Facebook Ads Spend Per Click Analysis
Calculated daily spend per click using Facebook Ads data and handled division by zero with `NULLIF`.

### 2. Facebook Ads KPI Analysis
Calculated key advertising KPIs such as total spend, impressions, clicks, CPC, CTR, CPM, and ROMI.

### 3. Facebook and Google Ads Union
Combined Facebook Ads and Google Ads data using `UNION ALL` to create a unified advertising dataset.

### 4. Campaign and Adset Performance Analysis
Joined Facebook Ads performance data with campaign and adset tables to analyze campaign-level and adset-level performance.

### 5. ROMI-Based Best Campaign Analysis
Identified the best-performing campaigns and adsets based on return on marketing investment.

### 6. Unified Ads Data Cleaning
Prepared a clean advertising dataset using `COALESCE` to handle null values across spend, impressions, clicks, reach, leads, and value columns.

### 7. Unified Ads Extra Task
Applied additional SQL logic to prepare advertising data for business reporting and dashboard use.

### 8. UTM Campaign Monthly KPI Analysis
Extracted `utm_campaign` values from URL parameters and calculated monthly KPIs including CTR, CPC, CPM, and ROMI.
